# A Note is never shown to anyone but the Student who wrote it

No screen, loader or query reads a Note's body outside its author's own Lesson page and Saved page. That includes the Course's Instructor and Platform Admins. An Instructor view of Student Notes would be useful for spotting where students are stuck, and we still don't build one: a Student writes freely only if private means private. Treat any screen that shows a Note to another person as a defect.
